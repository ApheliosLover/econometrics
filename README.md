# 计量经济学学习仓库

系统学习 **李子奈、潘文卿《计量经济学》（第五版）**，边学边把进度沉淀在这个仓库里。

- 目标：考博；学完接 **伍德里奇《计量经济学导论：现代观点》（第七版）**
- 节奏：**每天 2 小时**，全书 50 个单元，约 10 周
- 工具：Python（numpy / pandas / statsmodels）手算对照

---

## 每天 2 小时怎么用

固定四段。**顺序不要换**——先回忆后学习、先自己推后看答案，这两条是整个流程里唯一真正起作用的部分。

### ① 回看（10 分钟）· 不许翻书

打开 `DRILLS.md`，做「今日到期」那几题。在纸上答，或者对着空气讲一遍。

答不上来的，**不要马上翻书**，先标记 ❌。它会自动排进今天的笔记，在第 ④ 段重讲。

### ② 精读（55 分钟）· 两遍法

按 `STUDY-PLAN.md` 找到今天的单元，翻到指定页码（`python3 tools/bookpage.py 43` 查 PDF 页码）。

- **第一遍**：不停笔地读完，不查、不问、不纠结。目的只是知道这几页在讲什么、分几块。
- **第二遍**：逐句抠。凡是"这一步凭什么"，写进草稿纸的疑问栏，**当场不查**。攒到第 ④ 段一起处理。

中断去查证是这类学习最大的时间黑洞。你 9-14 那天的记录里能看出来：一个"什么叫离差形式"就能岔开很远。疑问攒着比追着好。

### ③ 复现（30 分钟）· 合书，白纸

这是四段里最重要的一段，也是唯一能把「读懂了」变成「推得出来」的一段。

合上书，在白纸上重做今天单元里 `STUDY-PLAN.md`「必须自推」那一栏的东西。

卡在哪一步，那一步就是你今天真正没学会的地方——**它比任何笔记都准确**。卡住了再开书，看完合上重推一遍。

> 李子奈这本书的推导密度低，大量步骤写成"可以证明"就过去了（高斯-马尔可夫定理、σ̂² 无偏性都是如此，书里直接引到《学习指南》）。考博考的恰恰是这些。这一段省不得。

### ④ 落笔（25 分钟）· 四件事一起做

1. **写当日笔记**：`cp templates/daily-note.md notes/YYYY-MM-DD-chNN-标题.md`，照模板填。
   - 模板里有 `[自推]` / `[看了才懂]` / `[还没推]` 三个标记，**每个结论都要挂一个**。二刷时只看后两类，效率差别很大。
2. **登记疑问**：把第 ② 段攒的问题挪进 `OPEN-QUESTIONS.md`。当天解决的直接写答案并划掉，没解决的留着——它会一直在那儿盯着你。
3. **出题**：从今天的内容里挑 2–3 个值得反复问的点，写进 `DRILLS.md`，排上复习日期（1 天 / 1 周 / 1 月）。第 ① 段标 ❌ 的题，日期重置回 1 天后。
4. **勾进度 + 提交**：在 `PROGRESS.md` 勾掉这一格，然后
   ```bash
   git add -A && git commit -m "U03 §2.6 建模实例" && git push -u origin claude/kind-maxwell-5b4w5e
   ```
   commit 历史本身就是一条时间线——哪天学了、学了多少、断了几天，一条 `git log --oneline` 全看得见。

### 每周一次（周末，额外 1 小时）

- 跑当周的 Python 复现（`code/` 目录），手算结果与 `statsmodels` 输出逐个对齐
- 扫一遍 `OPEN-QUESTIONS.md`：**超过两周没解决的问题，要么当周解决，要么降级成"知道有这回事"并注明理由**。欠条不能只进不出。

### 页码换算

教材 PDF 的页码有偏移，而且中途变过一次：

```
书 p.1–123   → PDF 页 = 书页 + 29
书 p.124–275 → PDF 页 = 书页 + 31
```

```bash
python3 tools/bookpage.py 43        # 单页
python3 tools/bookpage.py 105 148   # 范围
```
