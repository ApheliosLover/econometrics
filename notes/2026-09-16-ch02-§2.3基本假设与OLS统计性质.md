# §2.3 基本假设与普通最小二乘估计量的统计性质

> 教材：李子奈、潘文卿《计量经济学》第五版，书 p.36–42
> 配套：潘文卿、李子奈《学习指南与练习》第四版，第二章 p.6–28
> 整理日期：2026-09-16

---

## 0. 全节只在讲一个式子

整节从头到尾，研究对象只有一个：

$$\hat\beta_1 - \beta_1 = \sum k_i \mu_i$$

**估计值与真值之差，等于干扰项的一个加权和。** 权重 $k_i = x_i/\sum x_i^2$ 由 $X$ 决定。

§2.3 的全部内容，就是反复追问这一个式子的三件事：

1. 它平均是多少？ → 无偏性
2. 它波动多大？ → 有效性
3. $n\to\infty$ 时它去哪了？ → 一致性

三个问题，三条性质。

---

## 1. 第一层：这个式子本身不需要任何假设

推导只用到"$Y_i$ 是什么"这一件事：

```
β̂₁ = Σkᵢ Yᵢ                        ← 线性性，纯代数
    = Σkᵢ(β₀ + β₁Xᵢ + μᵢ)          ← 代入 Yᵢ 的定义
    = β₀·Σkᵢ + β₁·ΣkᵢXᵢ + Σkᵢμᵢ
         ↓ 0        ↓ 1
    = β₁ + Σkᵢμᵢ
```

中间的 0 和 1 来自 $k_i$ 的构造，同样是纯代数：

$$\sum k_i = \frac{\sum x_i}{\sum x_i^2} = 0 \qquad \sum k_i X_i = \frac{\sum x_i(x_i+\bar X)}{\sum x_i^2} = \frac{\sum x_i^2}{\sum x_i^2} = 1$$

### 为什么这里不需要假设

关键在于看清：**假设 1–5 全部是关于 $\mu$ 的分布的陈述**——$\mu$ 平均是多少（假设 3）、波动多大、彼此相不相关（假设 4）、长什么形状（假设 5）。

而上面这段推导**一次也没问过 $\mu$ 平均是多少**。它只是把 $Y_i$ 拆开、合并同类项。$\mu_1,\dots,\mu_n$ 是多少就是多少，是一堆具体的数——哪怕它们全是正的、全跟 $X$ 相关、全乱七八糟，这个等式照样成立。

> 类比：
> "总分 = 语文 + 数学" —— 对任何一个学生都成立，不需要知道全班成绩。
> "班级平均总分 = 平均语文 + 平均数学" —— 这一句才开始需要数据。
>
> $\hat\beta_1 = \beta_1 + \sum k_i\mu_i$ 是前一句。它是**恒等式**，不是关于平均的陈述。

这就是"每步用了哪条假设"表中线性性一行为空的原因。

---

## 2. 第二层：三个动作，三条性质，各要各的假设

假设只在你对那个式子**动手**时才被需要。能做的动作恰好三个：

| 动作 | 问的问题 | 得到 | 需要知道 μ 的什么 | 用哪条假设 |
|---|---|---|---|---|
| 取条件期望 $E(\cdot\|X)$ | 平均而言偏不偏？ | 无偏性 | $\mu$ 的**条件均值** | 假设 3 |
| 取条件方差 $\mathrm{Var}(\cdot\|X)$ | 波动多大？ | 精度 / 有效性 | $\mu$ 的**条件方差与协方差** | 假设 4 |
| 取概率极限 $\mathrm{plim}$ | $n\to\infty$ 时去哪？ | 一致性 | $\mu$ 与 $X$ 的**相关性** + $X$ 的方差 | 假设 2 + 同期外生 |

**这张表是 §2.3 的全部骨架。** 每条假设的存在理由，就是让其中一个动作做得下去。反过来，哪条假设违反会毁掉哪条性质，从表里直接读出来，不用背。

表外的两条：

- **假设 5**（正态性）管"$\mu$ 长什么形状"，要到 §2.4 做区间估计和 $t$ 检验时才用。
- **假设 1**（正确设定）站在表外——它保证你要估的那个 $\beta_1$ 确实存在、确实是你想要的东西；它垮了，后面三条性质都在估一个错的目标。

## 3. 三个动作逐个做

### 动作一：取条件期望 → 无偏性

$$E(\hat\beta_1|X) = E\big(\beta_1 + \textstyle\sum k_i\mu_i \,\big|\, X\big) = \beta_1 + \sum k_i \cdot E(\mu_i|X)$$

走到这里卡住：$E(\mu_i|X)$ 是多少？代数不告诉你，必须**假设**。假设 3 说它是 0，于是 $E(\hat\beta_1|X) = \beta_1$。

这一步还偷用了一件事：把 $k_i$ 从期望号里提出来当常数。凭什么？因为条件里给的是**全部** $X$，而 $k_i$ 完全由 $X$ 算出，给定 $X$ 后它就是个已知数字。

> **为什么条件必须是"所有 X"**：$k_i = (X_i-\bar X)/\sum_j(X_j-\bar X)^2$，分子的 $\bar X$ 与分母的求和都跑遍全部 $n$ 个观测。所以 $k_2$ 不只取决于 $X_2$，改动 $X_5$ 会让 $k_2$ 跟着变。只给定 $X_i$ 一个值，$k_i$ 仍是随机变量，提不出期望号。
>
> 假设 3 写成 $E(\mu_i|\mathbf X)=0$ 而非 $E(\mu_i|X_i)=0$，强度不多不少，恰好是无偏性所需。

### 动作二：取条件方差 → 精度与有效性

$$\mathrm{Var}(\hat\beta_1|X) = \mathrm{Var}\big(\textstyle\sum k_i\mu_i\big|X\big) = \sum k_i^2\,\mathrm{Var}(\mu_i|X) + 2\sum_{i<j} k_ik_j\,\mathrm{Cov}(\mu_i,\mu_j|X)$$

又卡住，这回卡在两处：$\mathrm{Var}(\mu_i|X)$ 是多少？$\mathrm{Cov}(\mu_i,\mu_j|X)$ 是多少？**假设 4 一次回答两个**——前者恒为 $\sigma^2$，后者为 0。于是

$$\mathrm{Var}(\hat\beta_1|X) = \sigma^2\sum k_i^2 = \frac{\sigma^2}{\sum x_i^2} \tag{2.3.16}$$

其中 $\sum k_i^2 = \sum x_i^2 / (\sum x_i^2)^2 = 1/\sum x_i^2$。

**易滑过的点**：交叉项是靠假设 4 的**后半条（不序列相关）**消掉的，不是只用了同方差。

BLUE 是在此基础上再问一句"别的线性无偏估计量能不能更小"，答案是不能。教材只给结论 $\mathrm{Var}(\hat\beta_1^*|X)\ge \mathrm{Var}(\hat\beta_1|X)$，证明见学习指南**例 8（指南 p.13–14）**。

### 动作三：取概率极限 → 一致性

$$\mathrm{plim}\,\hat\beta_1 = \beta_1 + \mathrm{plim}\Big(\sum k_i\mu_i\Big) = \beta_1 + \frac{\mathrm{plim}\big(\sum x_i\mu_i/n\big)}{\mathrm{plim}\big(\sum x_i^2/n\big)}$$

上下同除 $n$，是为了让分子分母各自变成**样本矩**，才好用大数定律。

第三次卡住：这两个极限是多少？大数定律说，分子收敛到 $\mathrm{Cov}(X_i,\mu_i)$，分母收敛到 $\mathrm{Var}(X_i)$。于是又得问这两个数是多少——**同期外生**给了分子 $=0$，**假设 2** 给了分母 $=Q$，非零有限。所以

$$\mathrm{plim}\,\hat\beta_1 = \beta_1 + \frac{0}{Q} = \beta_1$$

## 4. 为什么无偏与一致要求的强度不同

教材 p.42 开头的落点，现在可以看懂：

- **动作一**在**每一个有限的 $n$** 上做，条件里含全部 $X$，所以要求 $\mu_i$ 与**所有** $X$ 无关——严格外生，**强**。
- **动作三**只关心 $n\to\infty$ 的去向，只需样本协方差的极限为零，即 $\mu_i$ 只要与**自己那个** $X_i$ 无关——同期外生，**弱**。

| | 所需外生性 | 强度 |
|---|---|---|
| 无偏性（小样本） | $E(\mu_i\|X)=0$，严格外生 | 强 |
| 一致性（大样本） | $\mathrm{Cov}(X_i,\mu_i)=0$，同期外生 | 弱 |

于是有"**有偏但一致**"这一档：严格外生垮了（如含滞后因变量的模型 $Y_t=\beta_0+\beta_1Y_{t-1}+\mu_t$，$\mu_t$ 影响 $Y_t$ 而 $Y_t$ 正是 $t+1$ 期的解释变量），无偏性没了，但同期外生还在，一致性保住，结论仍可用。

**只假定 $E(\mu_i|X_i)=0$ 不足以保证无偏**——它能给同期不相关、从而给一致性，但给不了无偏性。无偏性与严格外生是绑死的一对。

## 5. $\hat\beta_0$ 那一半

完全平行，只换一套权重：

$$\hat\beta_0 = \sum w_i Y_i, \qquad w_i = \frac{1}{n} - \bar X k_i$$

代入后得 $\hat\beta_0 = \beta_0 + \sum w_i\mu_i$，三个动作照做一遍。

$w_i$ 的两条恒等式与 $k_i$ 的**正好对调**：

$$\sum w_i = 1 - \bar X\sum k_i = 1, \qquad \sum w_i X_i = \bar X - \bar X\sum k_iX_i = 0$$

方差：

$$\mathrm{Var}(\hat\beta_0|X) = \sigma^2\Big(\frac1n + \frac{\bar X^2}{\sum x_i^2}\Big) = \frac{\sigma^2\sum X_i^2}{n\sum x_i^2} \tag{2.3.17}$$

末步用离差恒等式 $\sum x_i^2 = \sum X_i^2 - n\bar X^2$ 反向代入。

读出的含义：$\bar X$ 离零越远，截距估得越不准——截距是把回归线外推到 $X=0$ 处的值，数据重心离 0 越远，外推越虚。

$\hat\beta_0$ 的一致性教材留作练习。

## 6. 五条基本假设速查（p.36–39）

| | 内容 | 要点 |
|---|---|---|
| 假设 1 | 回归模型正确设定 | 选对变量 + 选对函数形式；违反即设定偏误（第四章） |
| 假设 2 | $X$ 有变异性，$\mathrm{plim}\sum(X_i-\bar X)^2/n \to Q$，$0<Q<\infty$ | 有变异→否则 $\sum x_i^2=0$ 分母为零；$Q$ 有限→排除取值无界的变量 |
| 假设 3 | $E(\mu_i\|X)=0$ | 严格外生。最重要：只有它成立，PRF 随机形式 (2.1.7) 才等价于非随机形式 (2.1.4) |
| 假设 4 | $\mathrm{Var}(\mu_i\|X)=\sigma^2$；$\mathrm{Cov}(\mu_i,\mu_j\|X)=0$ | 同方差 + 不序列相关，两半各有用处 |
| 假设 5 | $\mu_i\|X \sim N(0,\sigma^2)$ | 小样本才关键；大样本由中心极限定理放松 |

### 6.1 假设 3 的要害：为什么这居然需要一条假设

> 教材 p.38 原文：「该假设最为重要，只有该假设成立时，总体回归函数的随机形式 (2.1.7)
> 才能等价于非随机形式 (2.1.4)。」
> 补记于 2026-09-16（读 U01 时回头补）。第 3.10 节已有该命题的证明，此处补的是**读法**。

两个式子的身份：

| | 式子 | 身份 |
|---|---|---|
| (2.1.4) 非随机形式 | $E(Y\|X)=\beta_0+\beta_1X$ | **想知道的**。PRF，一条确定的线 |
| (2.1.7) 随机形式 | $Y=\beta_0+\beta_1X+\mu$ | **能估计的**。PRM，描述某个个体 |

**绕晕点**：把 $\mu$ 定义成 $\mu:=Y-E(Y\|X)$（即 2.1.5），移项就得到 (2.1.7)，这一步不需要
任何假设。而且这样定义的话

$$E(\mu|X)=E\big(Y-E(Y|X)\,\big|\,X\big)=E(Y|X)-E(Y|X)=0$$

**自动成立**。那假设 3 到底在假设什么？

**关键是读的方向反了。** 实做研究时不是先有真实的 $E(Y\|X)$ 再定义 $\mu$，而是**先写下一个方程**
$Y=\beta_0+\beta_1X+\mu$，把所有没进模型的东西扫进 $\mu$。这时 $\beta_0,\beta_1$ 只是自己方程里的
两个符号，**没有任何东西保证它们就是条件期望线的截距和斜率**。假设 3 正是那个保证。

**具体例子**：真实世界 $Y=100+0.6X+0.3W+\nu$（$W$ 为财富，$E(\nu|X,W)=0$），
财富与收入正相关，设 $E(W|X)=2X$。收集不到 $W$，于是写下 $Y=\beta_0+\beta_1X+\mu$，
$\mu=0.3W+\nu$。

- **(2.1.7) 仍然成立** —— $\mu$ 就是这么凑出来的，代数上永远对。
- **(2.1.4) 塌了** —— 真实条件期望线是 $E(Y|X)=100+0.6X+0.3\cdot 2X=100+\mathbf{1.2}X$，
  斜率 1.2，而方程里写的 $\beta_1=0.6$。两个 $\beta_1$ 不是同一个东西。
  原因：$E(\mu|X)=0.3E(W|X)=0.6X\neq 0$。

> **一句话**：(2.1.7) 永远成立，因为 $\mu$ 是定义出来的；(2.1.4) 却不一定成立。
> **假设 3 是「这两个式子里的 $\beta$ 是同一套 $\beta$」的条件。**

**「等价」等价的是什么**：由第 3.10 节的恒等式 $E(Y|X)=\beta_0+\beta_1X+E(\mu|X)$（$*$，
本身不需假设）双向读，得 $E(\mu|X)=0$ ⟺ 两式描述同一条线。所以假设 3 不是让某个式子
成立，而是**把两个式子焊在一起**——既要 PRF 是条件期望线（目标），又要用含 $\mu$ 的式子
估计（手段），它是绑定两者的唯一条件。

**为什么致命**：假设 3 断了，OLS 照样跑、照样收敛，但收敛到的是被污染的斜率（上例收敛到
1.2 而非 0.6）。**不是估不准，是估的东西根本不是要的东西**——与 $\sigma^2$ 大导致的「估不准」
是两种病。第四章 §4.3 讲的就是这一条垮掉之后怎么办。

**划定 §2.4 的边界**：$t$ 检验检验 $H_0:\beta_1=0$。假设 3 垮了，被检验的那个 $\beta_1$ 根本不是
条件期望线的斜率——检验做得再漂亮，对象是错的。这就是假设 1 与假设 3 站在所有统计检验
**前面**的原因。

### 6.2 期望迭代法则（Law of Iterated Expectations）

$$E\big[E(Y|X)\big]=E(Y)$$

**白话**：先分组求平均，再把各组平均按**组的大小**加权平均，等于总平均。叫「迭代」是因为
期望套期望，由内往外算两次。内层 $E(Y|X)$ 是 $X$ 的函数、本身仍是随机变量；外层再对 $X$
的分布平一次，把 $X$ 平掉。

**用教材例 2.1.1 的 99 户验证**（组内户数 4,6,11,13,13,14,13,10,9,6）：

| 走法 | 算式 | 结果 |
|---|---|---|
| 直接算 | $161\,755/99$ | **1 633.89** |
| 迭代期望 | $\sum P(X=x)\cdot E(Y\|X=x)$ | **1 633.89** |
| ❌ 10 个条件均值简单平均 | $15\,950/10$ | 1 595.00（差 38.89） |

**最容易踩的坑**：权重必须是各组的概率（户数占比），不是 $1/10$。4 户的组与 14 户的组在总
平均里分量不同。推导中的形态是：$E[E(\mu|X)]$ 的外层期望是**对 $X$ 的真实分布**取的。

**第二章里出现三次**：

| 用处 | 式子 |
|---|---|
| (2.3.6) | $E(\mu_i)=E[E(\mu_i\|X)]=0$　条件零均值 ⟹ 非条件零均值 |
| (2.3.7) | $\mathrm{Cov}(X,\mu_i)=E(X\mu_i)=E[X\cdot E(\mu_i\|X)]=0$　严格外生 ⟹ 同期外生 |
| 无偏性 | $E(\hat\beta_1)=E[E(\hat\beta_1\|X)]=\beta_1$　条件无偏 ⟹ 无条件无偏 |

第二行同时用了两条性质：先「取出已知因子」把 $X$ 提到 $E(\mu_i|X)$ 外面，再用迭代法则消掉
外层期望。

**方向单向**：$E(\mu|X)=0\Rightarrow E(\mu)=0$，反之不成立（反例见 09-14 笔记 2.10 节）。
**加权平均等于零，不代表每一组都等于零。** 这个单向性正是 $E(\mu|X)=0$ 才是无偏性命门、
而 $E(\mu)=0$ 几乎免费的原因。

**由假设 3 推出的两个更弱结论**：

$$E(\mu_i) = E[E(\mu_i|X)] = 0 \tag{2.3.6}$$
$$\mathrm{Cov}(X,\mu_i) = E(X\mu_i) = 0 \tag{2.3.7}$$

**假设 4 的等价写法**（配合条件零均值）：

$$\mathrm{Var}(\mu_i|X) = E(\mu_i^2|X) \tag{2.3.11}$$
$$\mathrm{Cov}(\mu_i,\mu_j|X) = E(\mu_i\mu_j|X) = 0 \tag{2.3.13}$$

**两处教材细节**：

- p.37 体例声明：多数教材假设 $X$ 是固定的非随机变量，那在实验或可控条件下成立，但社会调查数据不具备这种特点，**本书认为 $X$ 是随机变量**。
- p.39 末对假设 5 的限定：若只含**原生**随机干扰，$n\to\infty$ 时正态性总满足；若还含**衍生**的随机误差，即使 $n\to\infty$ 也经常不满足。

前 4 条称高斯–马尔可夫假设；5 条齐备称 CLRM，此时

$$Y|X \sim N(\beta_0+\beta_1X,\ \sigma^2) \tag{2.3.15}$$

> 勘误：p.39 的 (2.3.11) 末尾书上印作 $\sigma$，应为 $\sigma^2$。

## 7. "条件化"到底在说什么

$E(\hat\beta_1|X)=\beta_1$ 描述的重复抽样实验：**把 $X$ 的取值配置按观测到的样子钉住，反复抽 $\mu$（从而抽 $Y$）**，每次算一个 $\hat\beta_1$，这些 $\hat\beta_1$ 的平均等于 $\beta_1$。钉住 $X$ 就等于钉住全部 $k_i$，随机性被赶到一个地方。

### 两种框架的区别

| | 固定 $X$ 框架（多数初中级教材） | 随机 $X$ + 条件化（第五版） |
|---|---|---|
| $X$ 的身份 | 根本不是随机变量 | 是随机变量 |
| 重复抽样 | $X$ 由设计者设定，每次只重抽 $\mu$ | $X$ 与 $Y$ 一起重抽，只是把分析放在"$X$ 恰好取到这组值"那一层 |
| 适用 | 实验、可控条件 | 社会调查数据 |

区别不是文字游戏：固定 $X$ 框架下 $\mathrm{Cov}(X,\mu)$ 这个写法**根本没有意义**——$X$ 不是随机变量，谈不上协方差。而内生性、工具变量、以及一致性证明里 $\mathrm{plim}(\sum x_i\mu_i/n)=\mathrm{Cov}(X_i,\mu_i)$ 这一步，全都需要 $X$ 是随机变量。第五版要把这些讲进来，就必须让 $X$ 随机，再用条件化把"钉住 $X$"这个好处拿回来。

准确说法：**$X$ 是随机的，我们只是选择站在"已知 $X$ 取了这组值"的那一层上做分析。**

### 条件化用在小样本，不是大样本

条件化 $E(\cdot|X)$ 用于**小样本（有限样本）性质**——无偏性、方差公式 (2.3.16)(2.3.17)，这些结论对 $n=20$ 和 $n=2000$ 一样成立。

到大样本性质（一致性）反而**不条件化**：$\mathrm{plim}\,\hat\beta_1 = \beta_1 + \mathrm{Cov}(X_i,\mu_i)/\mathrm{Var}(X_i)$，这里 $X$ 必须随机，且只需同期外生这个弱条件。

### 为什么要条件那一版

由期望迭代法则，条件无偏 $\Rightarrow$ 无条件无偏：

$$E(\hat\beta_1) = E\big[E(\hat\beta_1|X)\big] = \beta_1$$

反向不成立。而你真正需要的恰是条件那一版：手上只有一个样本，$X$ 组合就是这一组、不会重来。若只知道无条件无偏，逻辑上完全可能是"你这种 $X$ 组合下系统性偏高，被另一些你永远抽不到的组合偏低补平了"——对你毫无用处。条件无偏说的才是你要的那句：**就着你手上这批 $X$，估计量是瞄准的。**
