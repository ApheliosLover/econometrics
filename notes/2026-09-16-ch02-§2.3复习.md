1. 定了之后，条件期望是一个定值，如果相关的话，那后面的式子就不为 0，那就推不出无偏性

2. 因为一个 x 下有很多 y，因此我们只能找到一个期望的 y

3. 加数据减少随机误差，让观测都带着同一份污染。收敛是收敛的，只是收敛到了错误的地方

   > 校对：原话「**让**观测都带着同一份污染」，逻辑上应为「**但**」——
   > 加数据能平掉随机误差，**但**污染是每个观测都带着的同一个偏移，平不掉。

4. 条件化是指，这一次生成的 X 就不动了，用这个 X 来做观察

5. 内生性是指，那个 u，就是模型中的那个让 y 形成波动的 u，对 x 也有牵连

   > 校对：「**对** x」应为「**与** x」——「对」暗示了方向，而牵连不分方向。
   > 遗漏变量是 μ 里含 X，联立方程是 X 里含 μ，两个方向 OLS 都一样出错。

6. 因为 Y 看到的是 X 对 Y 总的影响，而在这其中 X 会通过 W 对 Y 造成影响，如果不写出来的话，OLS 会把第二个影响算到 X 的头上，这个过程就是存在内生性的过程

#### ⭐ 2026-09-18 我造的第一个例子（D-17）

挂了两天，这天补上。要造的结构：**A 的干扰项里，装着 B 的解释变量。**

```
观测单位：学生
Y：考试成绩
X：自己的学习时间

李四学习时间长 → 李四给张三讲题 → 张三成绩提高
                                  （张三自己一分钟没多学）
```

讲题提的那几分落进 μ_张三（模型里只有"张三自己的学习时间"，没有"同桌讲了多少题"），
而讲题量由李四学了多久决定，即 X_李四。所以 **Cov(μ_张三, X_李四) ≠ 0**。

**垮的是严格外生**（假设 3 条件里的 X 是整个向量，含李四）。
同期外生 Cov(X_张三, μ_张三) 垮不垮，取决于两人学习时间相不相关 —— 见 `OPEN-QUESTIONS.md` Q-013。
