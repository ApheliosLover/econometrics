# Python 复现

## 为什么是"手算 + 对照"而不是"调包"

调 `statsmodels.OLS` 三行就出结果，学不到东西。这里每个脚本都写成两列：

- **左列**：只用教材当节的公式，纯 numpy 一步步算出来
- **右列**：`statsmodels` 的标准输出
- **第三列**：教材上印的数

对不上的那一项，就是公式记错或理解错的地方。**这是唯一能自动发现"我以为我懂了"的办法**——纸上推导可以自欺，数字对不上不能。

正确用法：**先在纸上算，再跑脚本对答案。** 反过来就白做了。
