## 一、六块内容

### 1. 为什么假设 3 的条件必须是全部 X

无偏性推导走到：`E(β̂₁|X) = β₁ + Σ kᵢ·E(μᵢ|X)`，要它等于 β₁，**求和里每一项都得是 0**。

需要全部 X 有两层理由：

**技术层**：kᵢ = (Xᵢ − X̄) / Σⱼ(Xⱼ − X̄)²。X̄ 含全部 X，分母 Σⱼ 跑遍全部 j，所以 **kᵢ 由全部 X 决定**。数值演示（固定 X₂ = 5.0，只改 X₅）：

| X₅ | X̄ | Σ(Xⱼ−X̄)² | k₂ |
|---|---|---|---|
| 1.0 | 2.60 | 13.20 | 0.1818 |
| 3.0 | 3.00 | 10.00 | 0.2000 |
| 10.0 | 4.40 | 49.20 | 0.0122 |
| 30.0 | 8.40 | 593.20 | −0.0057 |

X₂ 一个数没动，k₂ 从 0.1818 变到 −0.0057，**连正负号都翻了**。所以只条件在 X₂ 上，k₂ 仍是随机变量，提不出期望号。

**实质层**：μᵢ 可能跟任何一个 Xⱼ 勾连，不只是 Xᵢ。

### 2. 期望迭代法则

`E[E(Y|X)] = E(Y)`。先分组求平均，再把各组平均**按组的概率**加权平均，等于总平均。

**唯一的坑**：权重必须是各组概率，不是简单平均。教材例 2.1.1 的 99 户：迭代期望 = 1633.89 = 直接算；简单平均 10 个条件均值 = 1595.00，错。

**推 (2.3.7)**：

```
Cov(Xᵢ, μᵢ) = E(Xᵢμᵢ) − E(Xᵢ)E(μᵢ)
E(μᵢ) = E[E(μᵢ|X)] = E[0] = 0          ← 迭代法则 + 假设 3，右项消失
E(Xᵢμᵢ) = E[E(Xᵢμᵢ|X)]                 ← 迭代法则
        = E[Xᵢ·E(μᵢ|X)]                 ← 取出已知因子
        = E[Xᵢ·0] = 0
⟹ Cov(Xᵢ, μᵢ) = 0
```

**反方向不成立**。反例：X 取 −1/0/1 各 1/3，E(μ|X) = X² − 2/3。则 E(μ) = 0、Cov(X,μ) = 0，但每个 X 点上 E(μ|X) ≠ 0。

### 3. 无偏性 vs 一致性 ⚠️ 此处有过错误理解

| | 问的问题 | 关于什么 |
|---|---|---|
| 无偏性 | 样本量就是 n，重复抽样无数次，β̂₁ 的**平均**等不等于 β₁ | 抽样分布的**中心位置** |
| 一致性 | n → ∞ 时 β̂₁ 会不会**收敛**到 β₁ | n 增大时的**去向** |

**「小样本性质」= 不需要大样本就成立，不是只在小样本成立。** 无偏性对 n=5000 一样成立。这是考试陷阱常客。

**两者互不蕴含**（`code/unbiased_vs_consistent.py`，真值 0.5 / 0.5）：

| 估计量 | n=10 | n=50 | n=500 | n=5000 | 判定 |
|---|---|---|---|---|---|
| A 全样本 OLS 均值 | 0.5037 | 0.4996 | 0.5002 | 0.5000 | 无偏 |
| A 标准差 | 0.3802 | 0.1464 | 0.0448 | 0.0141 | 一致 |
| B 只用前两观测 均值 | 0.4963 | 0.5053 | 0.5014 | 0.5129 | **无偏** |
| B 标准差 | 1.4009 | 1.4239 | 1.4123 | 1.4203 | **不一致**（纹丝不动） |
| C 滞后因变量 偏差 | −0.0708 | −0.0189 | −0.0020 | −0.0003 | **有偏但一致** |

B 还说明：外生性完美也可能不一致，一致性还需**假设 2** 保证信息随 n 累积。

### 4. plim

**plim β̂₁ = β₁** 意思是：对任意容差 ε > 0，`P(|β̂₁ − β₁| > ε) → 0`（n → ∞）。叫**依概率收敛**。

不能用普通 lim，因为 β̂₁ **不是数列**——每个 n 对应一个分布。同理假设 2 写 plim，因为 Σxᵢ²/n 是样本方差，本身是随机变量。

数值（真值 0.5）：

| n | 标准差 | P(\|β̂−0.5\|>0.1) | P(\|β̂−0.5\|>0.02) |
|---|---|---|---|
| 10 | 0.3797 | 77.4% | 95.5% |
| 50 | 0.1454 | 48.4% | 88.6% |
| 200 | 0.0711 | 16.1% | 77.6% |
| 1000 | 0.0318 | 0.2% | 53.1% |
| 5000 | 0.0142 | 0.0% | 16.0% |
| 50000 | 0.0027 | 0.0% | 0.0% |

**任何有限 n 上概率都不是 0**（n=1000 时偏离超 0.02 仍有 53%）。plim 说趋势，不是保证。

**教材没说但关键**：plim 有期望没有的性质（Slutsky）——`plim(A/B) = plim(A)/plim(B)`，只要 plim(B) ≠ 0。p.41 上下同除 n 后能分开取极限，靠的就是它；期望做不到（E(A/B) ≠ E(A)/E(B)）。这是一致性必须用 plim 的技术原因。plim(B) ≠ 0 由假设 2 的 Q ≠ 0 守着。

### 5. 严格外生 vs 同期外生，「有偏但一致」

```
严格外生   E(μᵢ | X₁,...,Xₙ) = 0      μᵢ 与【全部】X 无关      强 → 无偏性
同期外生   Cov(Xᵢ, μᵢ) = 0            μᵢ 只与【自己那个】Xᵢ 无关  弱 → 一致性
```

**「有偏但一致」必须写成两句**（缺前半句就没意思）：

- **有偏**：任何有限 n 上，E(β̂) ≠ β，有系统性偏差
- **一致**：n → ∞ 时偏差趋于 0，β̂ 依概率收敛到 β

**标准例子**：滞后因变量 `Yt = ρ·Y(t−1) + εt`。同期外生成立（Y(t−1) 在 εt 之前就定了）；严格外生不成立（t+1 期的解释变量是 Yt，而 Yt 里装着 εt）。

**为什么值得强调**：凡解释变量含滞后因变量的（宏观、金融、动态面板）一律不满足严格外生。不知道这个区别，会误以为 OLS 报废；实际一致性还在，大样本结论可用。真正报废的是连同期外生也垮（遗漏变量、反向因果、测量误差）——既有偏又不一致，须换工具变量（第四章 §4.3）。

### 6. 「μ₂ 与 X₅ 相关」为什么让 E(μ₂|X) ≠ 0

设 `μ₂ = 2·X₅ + ν₂`（ν₂ 纯噪声）。则

```
E(μ₂|X) = E(2X₅ + ν₂ | X) = 2·X₅ + 0 = 2·X₅
```

X₅ 是 X 的一部分，给定 X 后是已知数，直接提出来。若这次 X₅ = 3，则 E(μ₂|X) = 6 ≠ 0，那一项变成 k₂ × 6。

**同时同期外生完好**：X₂ 与 X₅ 独立 ⟹ E(μ₂|X₂) = 2E(X₅) = 0、Cov(X₂,μ₂) = 0。

**模拟验证**（n=6，只有第 2 个观测被污染，40 万次重复）：

```
Cov(X₂, μ₂) = −0.0002    同期外生成立
Cov(X₅, μ₂) = +2.0029    严格外生垮掉
真值 β₁ = 0.5    E(β̂₁) = 0.4344    偏差 −0.0656（62 倍标准误）
```

μ₂ 跟自己那个 X₂ 半点关系没有，只跟第 5 个观测的 X 有关，OLS 就已系统性偏低 13%。

## 二、五个追问

### Q1 「协方差只抓线性关系」怎么理解

`Cov(X,μ) = E[(X−EX)(μ−Eμ)]` 是**乘积的平均**，问的是单方向问题：「X 偏大时 μ 是不是也偏大？」

用 U 形反例（X 取 −1/0/1，E(μ|X) = X² − 2/3）：

| X | X 偏离 | μ 平均偏离 | 乘积 |
|---|---|---|---|
| −1 | −1 | +1/3 | −1/3 |
| 0 | 0 | −2/3 | 0 |
| +1 | +1 | +1/3 | +1/3 |

**正负相消，Cov = 0**。但 μ 强烈依赖 X——只是关系左右对称。协方差只问「是不是一头高一头低」，碰上「两头高中间低」一无所知。E(μ|X)=0 要求每个 X 点上都为零，U 形骗不过它。

### Q2 计量中大样本与小样本的地位

**现代计量绝对以大样本为主**（与「小样本因为有无偏性所以更好」的直觉相反）。四条理由：

1. 无偏性在现实中太难满足——严格外生对任何含滞后因变量的模型都不成立
2. 正态性假设只在小样本不可替代；大样本靠中心极限定理
3. **主流估计量多数根本没有无偏性**：IV/2SLS、ML、GMM 全是有偏的，只有一致性
4. 数据量变大。第五版序言明说这一版「适度引入大样本理论的相关内容」

小样本性质的地位：理解的起点，且数据确实少时（宏观年度数据、某些实验）是唯一能说的话。第五版序言原话是二者「具有同等程度的重要性」——那是在纠正过去只讲小样本的偏颇；实际研究中大样本是主场。

### Q5 ⭐「X 都定了，为什么条件均值还不为 0」

**这是当日最重要的一处澄清。**

「取条件均值时 X 不是都定了吗」——**对**。X 都定了，所以 E(μ₂|X) = 2X₅ 确实是个**定死的数**。若 X₅ = 3，它就是 6。

**问题恰恰在这儿：它是 6，不是 0。**

隐含的误解是「条件化把随机性消掉了，所以就没问题了」。但无偏性要的不是「没有随机性」，要的是**那个数等于零**：

```
E(β̂₁|X) = β₁ + k₂·E(μ₂|X) + ... = β₁ + k₂·6 + ... ≠ β₁
```

> **条件化的作用是「把 X 钉住，然后问 μ₂ 的平均值是多少」。**
> 钉住后答案是个确定的数，但**假设 3 要求这个数是 0**。
> μ₂ 跟 X₅ 有关，就意味着这个数随钉在哪儿而变：X₅=3 → 6；X₅=−1 → −2。就是不为 0。
>
> **假设 3 不是条件化之后自动成立的东西，它是一条要求。**
> 条件化只负责把问题问清楚，答案是 0 还是 6，取决于 μ 和 X 之间到底有没有勾连。
