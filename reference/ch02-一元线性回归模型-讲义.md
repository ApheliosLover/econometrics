## 2. 核心知识点

### 2.1 研究对象：为什么是 E(Y|X) 而不是 Y

教材 p.27 的定义：**回归分析关心的是根据解释变量的已知或给定值，考察被解释变量的总体均值。**

选择条件均值的四层理由：

1. **Y 与 X 之间写不成函数**。同一个 X 对应无穷多个 Y，不构成函数。取条件均值后才得到唯一确定的 E(Y\|X)。
2. **Y 中只有一部分是规律**。Y = E(Y\|X) + μ，后者是偶然、不可复制、不可由 X 解释的部分。
3. **条件均值是 MSE 意义下的最优预测**。在所有以 X 为自变量的预测规则 g(X) 中，使 E[(Y − g(X))²] 最小的是 g(X) = E(Y\|X)。
4. **政策含义本在均值上**。边际消费倾向本身就是总体平均意义的概念。

补充：关注条件**均值**是一种选择而非唯一可能。关心条件中位数 → 分位数回归；关心条件方差 → ARCH 族。经典计量选均值因其线性、可用 OLS、且与正态下的 ML 一致。

### 2.2 PRF 与 PRM

| | 总体回归函数 PRF | 总体回归模型 PRM |
|---|---|---|
| 式子 | E(Y\|X) = β₀+β₁X | Y = β₀+β₁X+μ |
| 含随机项 | 否 | 是 |
| 描述对象 | 给定 X 下所有个体的平均 | 某一个体 |

**命名规则**：不含 μ 称"函数"，含 μ 称"模型"。样本层面同理（SRF / SRM）。

**"含随机项才叫模型"的准确表述**：是**计量经济学模型**必须含随机项，而非"模型"一词本身要求。数理经济学中 Q = a − bP 也叫模型但不含随机项。含 μ 是计量模型区别于数理模型的标志。

**PRF 与 PRM 的分工**：PRF 是目标（要找的规律），PRM 是通道（数据是个体数据，必须经由含 μ 的形式才能估计）。二者在预测环节分道扬镳：
- 均值预测（目标在 PRF 上）：误差仅来自 β̂ 的抽样波动
- 个值预测（目标在 PRM 上）：误差中额外含 σ²，且不随 n→∞ 消失

*注：预测一节（§2.5）当日未学，此处仅为对话中提及的对照，待后续核对。*

### 2.3 PRF 是确定性关系还是统计关系

分两层：
- **Y 与 X**：统计依赖关系，非确定性函数关系。
- **E(Y\|X) 与 X**：确定性函数关系。给定 X，条件期望唯一确定。

回归分析的要点即在于：**通过取条件期望，把 Y 与 X 的非确定性统计关系，转化为 E(Y\|X) 与 X 的确定性函数关系**，从而可用函数形式刻画与估计。

### 2.4 SRF 与 PRF 的关系

| | PRF | SRF |
|---|---|---|
| 参数 | β 唯一、客观存在、**永远未知** | β̂ 可算，**随样本而变** |
| 误差 | μ 不可观测 | e（残差）可计算 |
| 性质 | 确定的一条线 | 随机的，每抽一次样得一条 |

三组对应：β̂ 估计 β；Ŷᵢ 估计 E(Y\|Xᵢ)；eᵢ 估计 μᵢ。

**易混点**：
- eᵢ ≠ μᵢ。μ 是相对总体均值的偏离，e 是相对样本回归线的偏离。
- yᵢ（离差，相对 Ȳ）≠ eᵢ（残差，相对回归线）。TSS 用前者，RSS 用后者。

### 2.5 符号约定

| 记号 | 含义 |
|---|---|
| 帽子 ^ | 估计值/估计量，**是随机变量** |
| 横杠 ‾ | 样本均值 |
| 小写字母 | 离差，xᵢ = Xᵢ − X̄ |
| 波浪号 ~ | 另一种估计量（用于与 OLS 对照，如证 BLUE 时的竞争者 β̃） |

注意 Ŷᵢ 估计的是 E(Y\|Xᵢ) 而非 Yᵢ；μᵢ 的估计量书中直接写作 eᵢ。

### 2.6 离差形式

定义 xᵢ = Xᵢ − X̄，yᵢ = Yᵢ − Ȳ。

**恒等式（后续推导反复使用）**：
- Σxᵢ = 0，Σyᵢ = 0
- Σxᵢ² = ΣXᵢ² − nX̄²
- Σxᵢyᵢ = ΣXᵢYᵢ − nX̄Ȳ = **ΣxᵢYᵢ**

**意义**：几何上是把原点平移到 (X̄, Ȳ)。因回归线必过该点，平移后截距为零。分子分母同除 n 后 β̂₁ = Cov(X,Y)/Var(X)，即"X 与 Y 共同变动的程度 ÷ X 自身变动的程度"。

### 2.7 拟合优度

**分解**：yᵢ = ŷᵢ + eᵢ，即"总离差 = 回归线解释的 + 未解释的"。

| 图中线段 | 记号 | 平方和 |
|---|---|---|
| Ŷᵢ 到 Ȳ | ŷᵢ | ESS |
| Yᵢ 到 Ŷᵢ | eᵢ | RSS |
| Yᵢ 到 Ȳ | yᵢ | TSS |

**ŷᵢ 的正确读法**：不是"点到线的距离"，而是**斜线（SRF）相对水平线（Ȳ）的抬升**，即引入 X 后预测值被抬高了多少，是 X 的增量贡献。由 ŷᵢ = β̂₁xᵢ 可知它取决于 β̂₁ ≠ 0 与 Xᵢ ≠ X̄；在 X = X̄ 处两线相交，ŷᵢ = 0。

**TSS 的本质**：只含截距的基准模型（对任何 X 都预测 Ȳ）的残差平方和。故 R² = 1 − RSS/TSS 读作"引入 X 后，预测误差比只用均值减少了多少比例"。

**R² 的使用提醒**：
- R² 高 ≠ 模型好。时间序列中带趋势变量易致伪回归；微观截面 R² 低属正常（个体异质性大 → σ² 天然高）。
- R² 随解释变量增加而单调上升 → 多元回归须用调整的 R̄²。
- 一元情形 R² = r²，多元无此对应。
- 分解式依赖截距项。无截距模型中 Σeᵢ = 0 不成立，R² 可能为负。

### 2.8 §2.3 五条基本假设（pp.36–39）

| 编号 | 内容 | 违反后果 |
|---|---|---|
| 1 | 模型正确设定（变量、函数形式） | 设定偏误 |
| 2 | plim Σ(Xᵢ−X̄)²/n → Q，0 < Q < ∞ | 不可估计 / 大样本推断失效 |
| 3 | **E(μᵢ\|X) = 0**（X 严格外生） | 内生性：有偏且不一致 |
| 4 | Var(μᵢ\|X) = σ²；Cov(μᵢ,μⱼ\|X) = 0 | 异方差、自相关 |
| 5 | μᵢ\|X ~ N(0, σ²) | 小样本精确推断失效 |

前 4 条称高斯-马尔可夫假设；5 条齐备称经典线性回归模型 CLRM。此时 **Y\|X ~ N(β₀+β₁X, σ²)**（图 2.3.2），Y 的条件分布被完整刻画。

**第五版的重要体例**（p.37 原文）：本书认为解释变量 X 是**随机变量**，不再假设它是固定的非随机变量；理由是社会调查数据不具备实验数据的可控性。因此全书假设一律写作条件形式。

**假设 3 为何"最重要"**（书中理由）：只有它成立，总体回归函数的随机形式 (2.1.7) 才等价于非随机形式 (2.1.4)，即所估计的线确实是条件期望线。由它可推出两个更弱结论：E(μᵢ) = 0（期望迭代法则）、Cov(Xᵢ,μᵢ) = 0（同期外生）。

**假设 2 两个限制的作用**：Q ≠ 0 保证 Σxᵢ² ≠ 0（否则 β̂₁ 分母为零）且 X 有变异可供解释；Q 有限用于排除样本方差发散的变量（非平稳时间序列），此为第九章伏笔。

### 2.9 外生性

**词源**：来自联立方程建模。内生变量由系统内部决定，外生变量由外部给定且不被系统反过来影响，判据是因果方向是否单向。

**移植到单方程**：系统内部除 X 外只有 μ，故"X 外生"落实为 **X 与 μ 无关**。

**三种破坏外生性的典型情形**：遗漏变量（遗漏因素进入 μ 且与 X 相关）、反向因果、测量误差。共同点是 X 与 μ 之间存在通道，X 不是纯粹的外部输入。

**强弱三档**：

| 名称 | 条件 | 强度 |
|---|---|---|
| 严格外生 | E(μᵢ \| X₁,…,Xₙ) = 0 | 最强 |
| 同期外生 | Cov(Xᵢ, μᵢ) = 0 | 较弱 |
| 内生 | Cov(Xᵢ, μᵢ) ≠ 0 | —— |

注意严格外生中的条件是**整个样本的所有 X**，要求 μᵢ 与任何一期的 X 都无关。典型违反者：含滞后因变量的模型 Yₜ = β₀+β₁Yₜ₋₁+μₜ（μₜ 影响 Yₜ，而 Yₜ 是下期的解释变量）——此类模型同期外生成立，OLS 有偏但一致。

**地位**：外生性是回归结果能被因果解读的全部依据。理想参照物是随机实验（X 由随机分配决定，必与 μ 无关）。工具变量、断点回归、双重差分等方法都在观测数据中寻找或制造接近随机的变异以恢复外生性。

### 2.10 条件零均值 vs 非条件零均值

- E(μ) = 0：所有个体混在一起的平均为零。
- E(μ\|X) = 0：**在任何给定 X 下**平均都为零。

由重期望公式，条件 ⟹ 非条件；反之不成立。反例：低收入组 μ 平均 −500、高收入组 +500，各占一半，则 E(μ) = 0 成立但 E(μ\|X) 随 X 变化。

**关键差别**：模型含截距时 E(μ) = 0 几乎自动成立（若 E(μ) = c ≠ 0 且与 X 无关，把 c 并入截距即可，斜率不受影响），因此它不构成实质约束；而 E(μ\|X) = 0 才真正禁止 μ 随 X 系统性变化，是无偏性的命门。

依赖强度由弱到强：Cov(X,μ) = 0（一致性）< E(μ\|X) = 0（无偏性）< μ 与 X 独立。

### 2.11 §2.3 三条统计性质（pp.39–41）

| 性质 | 结论 | 所用假设 |
|---|---|---|
| 线性性 | β̂₁ = ΣkᵢYᵢ | —— |
| 无偏性 | E(β̂₁\|X) = β₁ | **假设 3** |
| 有效性 | Var(β̂₁\|X) = σ²/Σxᵢ²，且为 BLUE | **假设 4** |
| 一致性 | plim β̂₁ = β₁ | 假设 2 + Cov(X,μ)=0 |

**高斯-马尔可夫定理**：OLS 是最佳线性无偏估计量（BLUE）。"最佳"限定在"线性无偏"范围内。

**方差公式的两点含义**：σ² 越大估计越不稳；X 越分散（Σxᵢ² 越大）估计越准。

**§2.3 的落点（p.42 开头，本节精髓）**：

| 性质 | 所需条件 | 强度 |
|---|---|---|
| 无偏性（小样本） | 严格外生 | 强 |
| 一致性（大样本） | 同期外生 | 弱 |

书中原文指出这一条件比严格外生要求弱。现实中许多模型满足不了严格外生，OLS 有偏但仍一致，结论可用；一旦连同期外生也不成立则既有偏又不一致，须换工具变量。

### 2.12 σ² 的含义

**三个易混量**：

| 符号 | 名称 | 层面 |
|---|---|---|
| σ² = Var(μ) | 扰动项方差 | 总体，未知参数 |
| RSS = Σeᵢ² | 残差平方和 | 样本，可算 |
| σ̂² = RSS/(n−2) | σ² 的无偏估计 | 样本，可算 |

σ² 度量给定 X 时 Y 在 PRF 周围的离散程度，是总体的客观属性，**不随样本量变化**。

**枢纽地位**：出现在 Var(β̂₁)、标准误、t 统计量、置信区间、预测区间之中。

**注意区分精度与拟合优度**：σ² 大 ≠ 模型错。只意味着个体差异大、预测单个个体不准，不意味着找到的规律是假的。

**与第四章的联系**：假设 4 要求 Var(μᵢ\|X) 对所有 i 相同。现实中方差可能随 X 变化（异方差），此时 β̂ 仍无偏，但方差公式失效 → SE 算错 → t 检验与置信区间失真。**异方差的危害在推断而非估计值本身。**

### 2.13 §2.4 一：β̂ 的分布与 σ² 的估计（pp.42–43）

**逻辑链**：做检验需知 β̂ 的抽样分布 → 分布由均值与方差决定 → 方差含 σ² → σ² 未知须估计。

**（1）概率分布**，三步推理：
1. β̂ 是 Yᵢ 的线性组合（线性性）
2. 由假设 5，Y\|X ~ N(β₀+β₁X, σ²)，即 (2.4.1)
3. 正态变量的线性组合仍正态

均值方差搬用 §2.3 结论，得 (2.4.2)(2.4.3)。

**大样本放松**（书中明载）：可将严格外生放松为同期无关，且**无须正态性假设**，只要样本观测点 i.i.d.，即得 (2.4.4)(2.4.5) 的**渐近**正态分布（符号由 ~ 改为 ≈）。故假设 5 真正不可替代的场合只有小样本。

**（2）σ² 的估计**：μ 不可观测，只能由残差出发。

**除 n−2 的理由**：eᵢ 是相对"为最小化 Σeᵢ² 而选出的"回归线的偏离，系统性小于 Σμᵢ²，除以 n 会低估。更精确的说法是自由度：n 个残差受两个约束（Σeᵢ = 0、ΣXᵢeᵢ = 0），独立的只有 n−2 个。多元回归为 n−k−1。

**带来的后果**（书中未明说，但为下一节 t 检验的基础）：σ² 已知时 (β̂₁−β₁)/(σ/√Σxᵢ²) ~ N(0,1)；用 σ̂² 替代后分母成为随机变量，统计量变胖尾，故 **(β̂₁−β₁)/S_β̂₁ ~ t(n−2)**。σ² 未知正是必须用 t 分布的原因。n 大时 t 收敛于正态。

## 3. 关键推导与公式

### 3.1 正规方程组（p.33）

最小化 Q = Σ(Yᵢ − β̂₀ − β̂₁Xᵢ)²，令两个偏导为零，得 (2.2.4)：

```
Σ(Yᵢ − β̂₀ − β̂₁Xᵢ) = 0      →   Σeᵢ = 0
ΣXᵢ(Yᵢ − β̂₀ − β̂₁Xᵢ) = 0    →   ΣXᵢeᵢ = 0
```

**这两条是 OLS 的核心性质，不是假设，而是最小化的必然结果。** "正规方程"的 normal 即"正交"之意。

### 3.2 离差形式（2.2.7）

β̂₁ = Σxᵢyᵢ / Σxᵢ²　　β̂₀ = Ȳ − β̂₁X̄

后者等价于 Ȳ = β̂₀ + β̂₁X̄，即**样本回归线必过均值点 (X̄, Ȳ)**。

### 3.3 ŷᵢ = β̂₁xᵢ（2.2.8）

```
Ŷᵢ = β̂₀ + β̂₁Xᵢ
Ȳ  = β̂₀ + β̂₁X̄ + ē,   ē = (1/n)Σeᵢ
相减：ŷᵢ = β̂₁(Xᵢ − X̄) − (1/n)Σeᵢ
由正规方程第一式 Σeᵢ = 0，末项消失，故 ŷᵢ = β̂₁xᵢ
```

用途：ESS = Σŷᵢ² = β̂₁²Σxᵢ²，即 R² 的简便算法 (2.2.12)。

### 3.4 交叉项为零（书中留作练习，对话中完成）

```
Σŷᵢeᵢ = Σβ̂₁xᵢeᵢ = β̂₁Σ(Xᵢ − X̄)eᵢ = β̂₁(ΣXᵢeᵢ − X̄Σeᵢ) = 0
```

第一步用 (2.2.8)，末步用正规方程两式。**故 TSS = ESS + RSS 不是巧合，而是 OLS 正交性的直接后果**；换一种估计方法或去掉截距，分解即不成立。

### 3.5 β̂₁ = ΣkᵢYᵢ 的证明

```
β̂₁ = Σxᵢyᵢ / Σxᵢ²

分子：Σxᵢyᵢ = Σxᵢ(Yᵢ − Ȳ) = ΣxᵢYᵢ − ȲΣxᵢ
     而 Σxᵢ = ΣXᵢ − nX̄ = 0
     故 Σxᵢyᵢ = ΣxᵢYᵢ

代回：β̂₁ = ΣxᵢYᵢ / Σxᵢ² = Σ(xᵢ/Σxᵢ²)Yᵢ = ΣkᵢYᵢ,  kᵢ = xᵢ/Σxᵢ²
```

**易错点**：Σxᵢ² 是一个数（求和后已无下标），可搬进求和号；kᵢ 分子带 i，分母不带 i。

### 3.6 关于 kᵢ 的三条恒等式

| 恒等式 | 证明要点 | 用于 |
|---|---|---|
| Σkᵢ = 0 | Σxᵢ = 0 | 无偏性 |
| ΣkᵢXᵢ = 1 | ΣxᵢXᵢ = Σxᵢ(xᵢ+X̄) = Σxᵢ² | 无偏性 |
| Σkᵢ² = 1/Σxᵢ² | 分子分母同为 Σxᵢ² 的幂 | 方差公式 |

### 3.7 核心式子

```
β̂₁ = ΣkᵢYᵢ = Σkᵢ(β₀+β₁Xᵢ+μᵢ) = β₀·Σkᵢ + β₁·ΣkᵢXᵢ + Σkᵢμᵢ
                                      ↓0          ↓1
```

> **β̂₁ = β₁ + Σkᵢμᵢ**　　（估计值 = 真值 + 扰动带来的误差）

无偏性、有效性、一致性三条全部由此读出。§2.3 后半只有这三块积木。

### 3.8 无偏性与方差

```
E(β̂₁|X)  = β₁ + Σkᵢ·E(μᵢ|X) = β₁                    ← 假设 3
Var(β̂₁|X) = Σkᵢ²·Var(μᵢ|X) = σ²Σkᵢ² = σ²/Σxᵢ²        ← 假设 4
```

**两步都以"给定 X 时 kᵢ 是常数"为前提。**

### 3.9 一致性

```
plim β̂₁ = β₁ + plim(Σxᵢμᵢ/n) / plim(Σxᵢ²/n)
        = β₁ + Cov(X,μ)/Var(X) = β₁ + 0/Q = β₁
```

Q 若为零则 0/0 无定义，一致性断裂——这是假设 2 的直接用处。

### 3.10 两边取条件期望的严格证明

**命题**　设 Y = β₀+β₁X+μ，则 E(Y\|X) = β₀+β₁X ⟺ E(μ\|X) = 0。

```
E(Y|X) = E(β₀+β₁X+μ | X)
       = E(β₀|X) + E(β₁X|X) + E(μ|X)        ← 条件期望的线性性
       = β₀ + β₁X + E(μ|X)                   ← 常数；"取出已知因子"
                                                                    (*)
(⟸) 若 E(μ|X)=0，代入 (*) 得 E(Y|X)=β₀+β₁X
(⟹) 若 E(Y|X)=β₀+β₁X，代入 (*) 两边消去得 E(μ|X)=0
```

**关键性质："取出已知因子"**：若 g(X) 是 X 的函数，则 E[g(X)·Z \| X] = g(X)·E(Z\|X)。因为条件期望的含义是"已知 X 后求平均"，X 的任何函数都已是已知数值。

**三点说明**：
1. (*) 式本身是恒等式，无需任何假设。假设 3 的作用是让右端第三项消失。
2. 同一条性质在证无偏性时以另一副面孔出现——把 kᵢ 提出期望号（kᵢ 是 X 的函数）。
3. 该等价关系说明假设 3 是定义性的：既要 PRF 是条件期望线（目标），又要用含 μ 的式子估计（手段），E(μ\|X)=0 是绑定两者的唯一条件。

### 3.11 σ̂² 与标准误（2.4.6、2.4.7）

```
σ̂² = Σeᵢ² / (n−2)                   （σ² 的无偏估计）
S²_β̂₁ = σ̂² / Σxᵢ²
S²_β̂₀ = σ̂² ΣXᵢ² / (nΣxᵢ²)
```

S_β̂₁ 即回归输出中的 Std. Error。

## 5. 对话中出现的误解与修正

### 5.1 关于第五版是否使用条件形式（AI 表述错误，已更正）

对话中期 AI 曾称"李子奈书里基本假设常写作 E(μᵢ)=0，属 X 非随机的框架"。**核对第五版 PDF 后确认此说法不成立**：第五版 p.37 明确写道，因社会调查数据不具备实验数据的可控性，**本书认为解释变量 X 是随机变量，不再假设它是固定的非随机变量**；假设 3、4 全部写成条件形式。

——教训：涉及具体版本的表述应以原书为准。

### 5.2 我曾认为"只要 RSS 最小就够了，不必讨论 TSS 与 ESS"

修正要点：

1. **RSS 最小是关于求解过程的陈述，不是关于模型好坏的陈述**。它只说"在所有直线中选了最好的一条"，不说"这条线值得要"。Y 与 X 毫不相关时 RSS 同样达到最小。
2. **RSS 是没有标尺的数**：随单位改变（元换万元则缩小 10⁸ 倍）、随 n 增大、跨数据集不可比。必须有参照物，参照物就是"不用 X 时的误差平方和"即 TSS。
3. 回归的目的本在 ESS 一侧（教材 p.35：用解释变量的变化解释被解释变量的变化）。
4. **分解式是统计检验的代数基础**：F 检验、方差分析表、σ̂² 全部建于其上。

一句话：最小化 RSS 回答"哪条线最好"，TSS 与 ESS 回答"这条最好的线好不好、值不值得信"。

### 5.3 对 ŷᵢ 的理解偏差

曾按"点到线的距离"去读图 2.2.1 中的 ŷᵢ。正确读法见 2.7 节：**它是斜线相对水平线 Ȳ 的抬升**，量的是 X 的增量贡献。

### 5.4 "找让 μ 的 MSE 最小的那条线"这一表述的循环问题

见第 4 节对应条目。顺序应为：先最优化 → 后定义 μ。
